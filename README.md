# AgroWise

Smart Technology for Smarter Farming.

## Current stage

Step 1: Flask + custom HTML/CSS/JS landing page.

No Bootstrap and no SQLite.

## Run

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py
```

Open http://127.0.0.1:5000
